Cómo configurar tu clave:
OpenAI: normalmente de pago Gemini: suele tener cuota gratuita Claude: normalmente de pago
  1. Abre la página de IA desde la barra de navegación superior: IA.
  2. Elige el proveedor que quieras usar: OpenAI, Gemini o Claude.
  3. Entra en la cuenta del proveedor y crea o copia la clave API desde su panel de desarrolladores:
    • OpenAI: debe empezar por sk- y suele ser de pago. OpenAI API Keys.
    • Gemini: debe empezar por AIza... y suele tener un nivel gratuito. Google AI Studio.
    • Claude: debe empezar por sk-ant- y suele ser de pago. Anthropic Console.
  4. Pega la clave en el campo Clave API de esta pantalla.
  5. Guarda la configuración. La clave se almacena en el servidor, no en el navegador.

Si pegas una clave de otro proveedor en el campo equivocado, la aplicación rechazará la configuración para prevenir errores 401.

Si un administrador fuerza una IA para tu cuenta, esa configuración tiene prioridad y la opción del usuario queda bloqueada.
